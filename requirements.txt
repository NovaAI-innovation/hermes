# Runtime dependencies for the hermes-docs-qdrant plugin.
#
# This is the file to install, and it is safe to install into the Hermes
# environment: it contains nothing that conflicts with Hermes core.
#
#   python -m pip install -r requirements.txt
#   hermes gateway restart          # a running process never switches envs
#
# The corpus build toolchain (crawl4ai, tiktoken, sentence-transformers) lives
# in requirements-build.txt and must go in a SEPARATE environment. crawl4ai
# pins snowballstemmer<3, which is unsatisfiable against Hermes core's
# snowballstemmer==3.1.1 on Python >= 3.14 — adding it here is what previously
# left the plugin's dependencies unresolved and its tools silently hidden.
#
# NOTE: faiss-cpu / rank-bm25 are NOT listed. They belong to the FAISS
# reference implementation described in POST_SCRAPE_PIPELINE.md; production is
# Qdrant.

-r requirements-runtime.txt
